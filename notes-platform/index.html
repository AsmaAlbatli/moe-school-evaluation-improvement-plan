أكمل ربط المنصة بـ Supabase

تحتاج المنصة إلى مشروع Supabase واحد لتخزين الملاحظات ومزامنتها بين أعضاء الفريق. الإعداد يستغرق دقائق قليلة.

دخول تجريبي مؤقت للمعاينة فقط — البيانات لا تُحفظ

ادخل بالحساب التجريبي

جرّب المنصة الآن دون إعداد Supabase. هذا الحساب عام ومخصص للعرض فقط، ولا يصلح للبيانات الحقيقية.

البريد: demo@school.edu.sa كلمة المرور: Demo@2026
1

أنشئ مشروع Supabase

من لوحة التحكم، أنشئ مشروعًا جديدًا ثم افتح SQL Editor.

2

نفّذ مخطط قاعدة البيانات

الصق محتوى الملف notes-platform/supabase/schema.sql كاملًا ثم اضغط Run.

3

أضف الإعدادات العامة

افتح الملف notes-platform/assets/js/supabase-config.js وأضف Project URL وanon / publishable key.

4

أنشئ حسابات الفريق

سجّل حسابًا لكل عضو، ثم أوقف التسجيل العام من إعدادات Supabase Auth بعد الانتهاء.

window.NOTES_SUPABASE = { url: "https://YOUR-PROJECT.supabase.co", anonKey: "YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY", allowSignup: true};
تنبيه أمني: استخدم فقط مفتاح anon / publishable العام. لا تضع أبدًا مفتاح service_role أو أي مفتاح سري في ملفات المتصفح. الحماية الفعلية تأتي من سياسات RLS المضمنة في المخطط.

مساحة عمل الفريق

اجمع الملاحظات، حدّد المسؤول، وتابع الإغلاق في مكان واحد.

منصة متابعة عربية تربط كل ملاحظة بتوصية وإجراء تصحيحي ومسؤول وتاريخ استهداف، مع لوحة مؤشرات تُحدَّث فورًا بعد كل إضافة أو تعديل.

  • لوحة مؤشرات فوريةإجمالي الملاحظات، الجديدة، قيد المعالجة، والمغلقة.
  • تصفية دقيقةحسب الحالة، الأولوية، المجال، المسؤول، والاستحقاق.
  • توصيات وإجراءات تصحيحيةلكل ملاحظة توصية وإجراء، مع تنبيهات للمتأخرات.
  • مزامنة سحابية آمنةSupabase مع حماية RLS لحسابات الفريق المسجّلة.
