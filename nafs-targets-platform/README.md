# منصة متابعة مستهدفات نافس

<div align="center">

**منصة مستهدفات نافس — نسخة وزارة التعليم**

منصة تفاعلية تعمل داخل المتصفح لتحليل بطاقات نافس، وقراءة ملفات PDF والصور،
ومقارنة المدارس بالمستهدفات الوطنية، مع تحديد مستوى كل مرحلة وفق القراءات
وخط الأساس.

</div>

---

## التشغيل

افتح `index.html` بالنقر المزدوج (يعمل مباشرة من المتصفح)، أو شغّل سيرفرًا محليًا:

```bash
python -m http.server 8777
# ثم افتح: http://127.0.0.1:8777/nafs-targets-platform/index.html
```

> كل البيانات تُحفظ في `localStorage` داخل جهازك فقط، ولا تُرسل إلى أي خادم.
> الاستثناء الوحيد: تحميل محرك التعرّف الضوئي (Tesseract) عند قراءة الصور
> لأول مرة — ويجري مرة واحدة ثم يُخزَّن في ذاكرة المتصفح.

## ما تقوم به المنصة

| الميزة | الوصف |
|---|---|
| **قراءة PDF** | استخراج البطاقة من ملف PDF نصي: بيانات المدرسة، نسب الإتقان، التوزيع، الرسوم البيانية والمستهدفات. |
| **قراءة الصور** | تُقرأ صور البطاقة بالتعرّف الضوئي وتحليل ألوان الرسوم داخل الجهاز، وتُعلَّم قيمها «تقديرية» للمراجعة. |
| **قراءة بيانات المدرسة** | تقرأ «اسم المدرسة» و«الرقم الوزاري» وبقية الحقول من البطاقة حتى لو كانت القيمة **في السطر نفسه** beside التسمية، وتتحمّل أخطاء التعرّف الضوئي في التسمية، مع قراءة مكبَّرة للرقم الوزاري. |
| **رفع ملفات متعدد** | إفلات عدة ملفات دفعة واحدة (PDF وصور معًا)، وتُحفظ البطاقات في «البطاقات المحفوظة». |
| **تحديد مستوى كل مرحلة** | تبويب مستقل: تُحدَّد نسبة كل مجال ومستواه وحالته يدويًا أو تلقائيًا وفق القراءة وخط الأساس. |
| **خط الأساس القابل للتعديل** | تعديل خط الأساس 2023 ومستهدفي 2026 و2030 لكل صف ومادة، وتُطبَّق فورًا على كل البطاقات. |
| **مقارنة المدارس** | مقارنة مدارس الصف نفسه بالمستهدفات، مع حالة كل مجال: حقق المستهدف / دون المستهدف / دون خط الأساس. |
| **الطباعة** | تقرير A4 بترويسة وزارة التعليم (الهوية الوطنية الخضراء)، مع قسم «خط الأساس والمستويات». |
| **التصدير** | Excel (كل البطاقات + ورقة «خط الأساس والمستويات»)، وWord (.docx) قابل للتحرير، ونسخة JSON احتياطية، وملف بطاقة مفرد. |
| **الاستيراد** | استيراد نسخة احتياطية JSON أو بطاقة محفوظة، بطول عمر البيانات على الجهاز. |

## تبويبات المنصة

1. **الرئيسية** — رفع البطاقة (PDF أو صور) ومتابعة شريط التقدّم.
2. **موقع المدرسة من المستهدفات** — موقع المدرسة من المستهدفات الوطنية مع قراءة النتائج.
3. **مقارنة المدارس** — مقارنة مدارس الصف الواحد (الفجوة = نتيجة المدرسة − مستهدف 2026).
4. **جدول المستهدفات** — المرجع الوطني لكل صف ومادة.
5. **بيانات البطاقة** — بيانات المدرسة والصف وبنية البطاقة المكتشفة (اسم المدرسة، الرقم الوزاري، الجنس، المنطقة، المرحلة، الصف، العام الدراسي، عدد الطلبة والمختبرون).
6. **مراجعة البيانات** — تحرير كل القيم المستخرجة وثقتها.
7. **خط الأساس والمستويات** — (إضافة) حدود المستويات، خط الأساس القابل للتعديل، وتحديد مستوى كل مرحلة.
8. **الإعدادات** — حدود التصنيف، أوزان الأولوية، ترويسة الطباعة والشعار، النسخ الاحتياطي.

## تحديد مستوى كل مرحلة

المرجع الأساسي: **خط الأساس الوطني 2023** لكل (صف + مادة)، ومنه تُبنى المستهدفات.

| العنصر | السلوك |
|---|---|
| **المستوى** | يُشتق تلقائيًا من نسبة الإتقان المقروءة: تهيئة < 50٪ · انطلاق 50–75٪ · تقدم 75–90٪ · تميز ≥ 90٪ (الحدود قابلة للتعديل). |
| **الحالة** | تُشتق من القراءة مقابل خط الأساس: ✅ حققت مستهدف 2026 · ⚠️ دون المستهدف وفوق خط الأساس · 🔴 دون خط الأساس 2023. |
| **التحديد اليدوي** | تثبيت المستوى أو الحالة لكل مجال من قائمة منسدلة، مع زر «تحديد تلقائي لكل المستويات» و«إلغاء التحديد اليدوي». |
| **خط الأساس** | تعديل أي قيمة في جدول (الصف × المادة) يُطبَّق فورًا على جميع البطاقات المحلَّلة وعلى الملفات التي ستُرفع لاحقًا. |
| **الانعكاس** | المستوى والحالة يظهران في تبويب «خط الأساس والمستويات»، وفي مقارنة المدارس، وفي التقرير المطبوع، وفي ورقة Excel. |

## الألوان والهوية

- اللون الأساسي: **أخضر وزارة التعليم** — `#173a34` (الرأس والجداول) و`#1b8354` (التفاصيل) و`#3f9c80` (ترويسة الطباعة).
- اللون الذهبي باقٍ كلون ثانوي للتمييز البصري فقط.
- ترويسة الطباعة: تصميم **الهوية الوطنية** مع شعار وزارة التعليم (SVG مضمَّن) وإطار أخضر.
- التوقيع أسفل الواجهة وأسفل التقرير المطبوع وفي ملف Word: **تصميم المشرفة أسماء الباتلي — وزارة التعليم**.

## التقنيات

HTML و CSS و JavaScript فقط — ملف واحد بلا أدوات بناء. مكتبتا `pdf.js` مضمَّنة داخل
الملف، ومحرّك `tesseract.js` يُحمَّل عند الحاجة إلى قراءة الصور فقط.

## تنبيه

القراءة آلية وقد تُخطئ في بعض الأرقام أو الكلمات (خصوصًا في الصور)، لذا يُنصح
بمراجعة البنود في «مراجعة البيانات» قبل الطباعة والاعتماد الرسمي.
