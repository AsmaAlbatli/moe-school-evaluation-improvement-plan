# منصة تفريغ خطة التحسين في منصة تميز

منصة عربية (RTL) لتفريغ خطة التحسين وفق منصة تميز الرقمية، بهوية خضراء رسمية،
وبناء كامل من المجال ← المعيار ← المؤشر ← بيانات الخطة، مع المراجعة والإقرار
والطباعة والتصدير.

**تصميم المشرفة أسماء الباتلي**

---

## أبرز المزايا

- **بناء الخطة:** اختيار المجال والمعيار والمؤشر، ثم تعبئة الاحتياج وإجراءات
  التحسين وآليات التنفيذ والمسؤولية والمدة والدرجات.
- **توليد سريع:** لصق نص تقرير التقويم أو إدخال الدرجات مباشرة، ثم توليد الخطط
  للمؤشرات المحددة أو لما دون التميز.
- **استيراد تقارير PDF:** قراءة محلية على الجهاز، مع دعم الملفات النصية
  والملفات المصوّرة عبر التعرّف الضوئي (OCR) بالعربية والإنجليزية.
  إذا كانت جميع صفوف البطاقة المصوّرة سليمة تُعتمد درجاتها تلقائيًا، مع بيان
  المؤشرات التي لم ترد في البطاقة لتبقى فارغة بدل تخمينها.
  يدعم أيضًا تقارير **التقويم الخارجي 2025** ذات عمود الرمز/الدرجة/المستوى
  على يمين الصفحة، ويحوّل رموزها إلى بنك مؤشرات المنصة تلقائيًا.
  كما يقرأ **تقارير التقويم الذاتي** التي تعرض المؤشر والدرجة والمستوى الحالي
  دون رموز، ويطابق عناوين المؤشرات ببنك المنصة ثم يعتمد الدرجات.
- **المراجعة والإقرار:** مراجعة الخطط، الإقرار، التوقيع، وإضافة الملاحظات.
- **الطباعة والتصدير:** طباعة منسّقة، طباعة النموذج الفارغ، وتصدير Word.
- **النسخ الاحتياطي:** تصدير واستعادة نسخة JSON، وحفظ تلقائي في المتصفح.
- **قائمة منسدلة مفعّلة:** تنقّل سريع وإجراءات (حفظ، طباعة، تصدير، نسخة
  احتياطية، استعادة، مسح) مع دعم لوحة المفاتيح.
- **إعدادات الهوية:** شعار المدرسة، بياناتها، ومظهر الهوية الخضراء.

## التشغيل

### الطريقة الأولى — سيرفر محلي (موصى به)

شغّل `تشغيل المنصة.bat` ثم افتح:

`http://127.0.0.1:8792/index.html`

### الطريقة الثانية — فتح مباشر

افتح `index.html` بالنقر المزدوج. تعمل معظم المزايا مباشرة، لكن استيراد PDF
والتعرّف الضوئي يحتاجان التشغيل عبر سيرفر محلي لقيود أمان المتصفح.

> **الخصوصية:** لا تُرفع بيانات المدرسة أو التقارير إلى أي خادم. القراءة
> والمعالجة تتم داخل المتصفح، والمكتبات (PDF.js وTesseract) مضمّنة محليًا.

## المتطلبات

- متصفح حديث (Chrome أو Edge أو Firefox أو Safari).
- Python 3 لتشغيل السيرفر المحلي فقط (اختياري).
